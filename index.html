      Format input dan default patch
      Masukkan 9 Bass DI untuk mempertahankan nomor channel, atau Bass DI untuk penomoran otomatis. Untuk patch khusus, gunakan 9 | Bass DI | AES50-A 15. Patch kosong mengikuti Local 1–32. Patch menerima Local, AES50-A, AES50-B, Card, Aux, dan OFF.
